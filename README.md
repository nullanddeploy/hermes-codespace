# Hermes Agent Codespace

Auto-starting Hermes agent on GitHub Codespaces.

## How it works
- On codespace creation: Hermes is installed automatically
- On every codespace start: Hermes dashboard (port 9119) and gateway start automatically
- No terminal commands needed!

## First-time setup
1. Create codespace from this repo
2. Open the dashboard (port 9119, set to Public)
3. Configure your model API key and Telegram via the dashboard UI
4. Done!

## Ports
- 9119: Hermes Dashboard (set to Public for phone access)
